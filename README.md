# notAgainPlease

notAgainPlease is a small, open-source Chrome extension designed to make job applications less repetitive.

The idea is simple: upload your CV once, review the information, and let the extension help fill in common application forms.

The project aims to be:

- simple to use;
- open source;
- useful in everyday applications;
- respectful of privacy, keeping personal data locally whenever possible.

This project is still at the beginning. The goal is to build it step by step and keep it useful, understandable, and easy to improve.
